# Tienda en Línea - E-commerce Web App

Un sistema de comercio electrónico desarrollado desde para la gestión y venta de productos. Este proyecto incluye autenticación de usuarios, catálogo de productos y funcionalidad de carrito de compras.

## Características Principales

* **Sistema de Usuarios:** Registro de cuentas nuevas, inicio de sesión seguro y manejo de sesiones activas.
* **Catálogo Dinámico:** Sección de consulta para visualizar los productos disponibles en la tienda.
* **Carrito de Compras:** Sistema para agregar productos y gestionar pedidos por usuario.
* **Interfaz Responsiva:** Diseño adaptable a dispositivos móviles y escritorio usando Bootstrap.
* **Gestión de Base de Datos:** Manejo de datos mediante phpMyadmin

## Requisitos Previos

Para ejecutar este proyecto en tu entorno local, necesitarás tener instalado:

* Un servidor web local con soporte para PHP (como XAMPP, WAMP, o contenedores Docker).
* Un gestor de base de datos MySQL (por ejemplo, phpMyAdmin).
* Git (opcional, para clonar el repositorio).
